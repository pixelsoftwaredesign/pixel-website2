LEÇON 1

Router-Dispatcher

Un routeur analyse la requête et l'aiguille vers un SLM (rapide) ou un LLM (capable).

Stratégies

Règles explicites, classifieur léger, cascade (essayer le SLM, escalader si confiance faible). Critères : coût, latence, qualité, taux d'escalade.

À retenir. Sous-estimer le coût d'un mauvais routage est le piège classique.
Exercice 1 - Routage

Quelle stratégie escalade automatiquement si le SLM est incertain ?

LEÇON 2

Cache sémantique

Réutiliser des réponses similaires pour réduire la latence TTFT et le coût.

Principe

Comparer le plongement de la requête à ceux des requêtes traitées. Si similarité > seuil, renvoyer la réponse stockée. Invalidation : TTL, versionnage. Sécurité : ne pas cacher de PII, cloisonner par utilisateur.

À retenir. Le seuil est un compromis : trop bas = mauvaises réponses, trop haut = cache inutile.
Exercice 2 - Cache

Que se passe-t-il si le seuil de similarité est trop bas ?

LEÇON 3

Agents ReAct

Un agent raisonne, agit (appel d'outil), observe, et itère jusqu'à une réponse.

Boucle

Pensée → Action → Observation → Pensée... Bonnes pratiques : outils restreints et typés, plafond d'itérations, journalisation. Risques : boucles infinies, injection via observations.

À retenir. Un agent sans garde-fous peut boucler indéfiniment ou exécuter des actions non autorisées.
Exercice 3 - Agents

Quel risque principal d'un agent ReAct sans plafond d'itérations ?

LEÇON 4

Résilience (Circuit Breaker)

Empêcher qu'une panne locale devienne une panne générale.

États

Fermé (appels passent), Ouvert (refus immédiat après seuil d'échecs), Semi-ouvert (tests). Patterns associés : timeouts, reprises, bulkheads, dégradation gracieuse.

À retenir. Le Circuit Breaker protège le système en refusant les appels vers un service défaillant.
